# Public atlas index

This directory is the human-readable companion to the machine-readable records
in `data/relation_atlas/`. The paper remains the authority for proofs.

## Primary reader path

1. `EXECUTABLE_REPLAY_SCOPE.md` — exact boundary between proofs, finite
   certificates, and metadata.
2. `RELATION_ATLAS_V2_PACKAGE_MANIFEST.md` — complete public artifact map.
3. `CF_THEOREM_TRANSFER_REGISTRY_V2.md` — current registry/readout index.
4. `CF_OPEN_PROBLEM_ATLAS_V2.md` — explicit unresolved conditions and excluded
   transfers.

## Supplementary records

- `CF_THEOREM_TRANSFER_REGISTRY_V1.md` preserves the 20-row base registry.
- `CF_THEOREM_ATLAS_V2_READOUT.md` reconciles the V2 counts and claim classes.
- `CF_LIKE_EDGE_WATCH_TRIAGE_V1.md` records the finite classification of eight
  coefficient-match rows as known metadata.
- `SUN_3_5_SEPARATE_PAPER_STATUS_UPDATE.md` separates the Sun 3.5 result from
  claims proved by the C/F bridge.

Every referenced path in the public manifest is checked mechanically by
`scripts/verify_public_package.py`.
